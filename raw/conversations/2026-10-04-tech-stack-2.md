# 2026-10-04 — Tech stack, round 2

Kind: design conversation. The designer answered the four tech-stack
questions (Q-034). The questions are paraphrased; the answers are verbatim.

## Questions asked (paraphrased)

1. Browser target: current Chrome/Edge, Firefox and Safari, on desktop and
   mobile?
2. Graphics: WebGPU with a WebGL2 fallback, or WebGPU only?
3. Keep WebRTC-direct as a second browser → server transport next to
   WebTransport?
4. Approve the rest: background Web Worker (one tab per player), OPFS storage,
   Ed25519 via WebCrypto, installable PWA, glTF with meshopt + KTX2 and AVIF
   images, TypeScript?

## Designer's answers (verbatim)

> 1. Only desktop is the current focus
> 2. WebGPU with fall back
> 3. Yes, WebRTC-direct as fall back
> 4. Approved

## Summary of what was decided

- Browser target: desktop browsers only for now (current Chrome/Edge, Firefox,
  Safari). Mobile is not a focus.
- WebGPU with a WebGL2 fallback.
- WebRTC-direct is kept as the fallback browser → server transport; WebTransport
  stays primary.
- Approved: Web Worker + one tab per player (Web Locks), OPFS, Ed25519 via
  WebCrypto, PWA, glTF with meshopt + KTX2, AVIF, TypeScript (resolves Q-034).
