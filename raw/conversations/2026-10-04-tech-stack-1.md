## Summary of what was decided

- Q-031, Q-032, Q-033 and Q-017 approved as proposed; the emergency
  delisting tool is kept (REG-008).
- Tech-stack principle: prefer modern, state-of-the-art web technology wherever
  it gives a real improvement, even at some cost in browser compatibility
  (→ D-0011).
- WebTransport instead of WebSockets. Clarification recorded by the LLM:
  browsers can only *dial* WebTransport connections to a server; they can't
  accept them. So WebTransport covers browser ↔ server (as in IPFS), and
  browser ↔ browser connections use WebRTC, as in libp2p. WebSockets are not
  used.
- Use IPv6 wherever possible to improve peer-to-peer connectivity.
