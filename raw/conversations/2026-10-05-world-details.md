# 2026-10-05 — World details

Kind: design conversation. The LLM proposed world details in five areas and
asked seven questions:
1. Spawn hub with the Creation Shrine, a rest point, a "New Peerlings" gallery
   (latest published Peerlings as 3D models on pedestals, loaded from IPFS) and
   a network monument visualizing live network activity?
2. Rest points as a common beacon silhouette dressed per biome, plus one big,
   generated-name landmark per biome area?
3. Paths connecting rest points and the spawn, bridges over rivers, signposts
   with area name and level range?
4. A minimap and world map that fill in as the player explores?
5. Environment art: (a) a hand-made low-poly kit shipped with the game app, or
   (b) made once by the operator with the AI pipeline and stored on IPFS?
6. A day/night cycle and weather per biome, tied to the shared epoch clock?
7. The generator-update plan: version switch announced in epoch records, all
   past generator versions kept for verification, players on newly blocked
   tiles moved to the nearest walkable tile, additive updates preferred?
Also proposed: terrain height with per-biome character, an ocean ring as the
border, per-biome prop kits placed deterministically.
